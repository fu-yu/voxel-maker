# 「風景を作る」タブを足す

日付: 2026-11-13

## 目的
ユーザーが公開中のページについて「ここで風景のようなボクセルを作れる?」と聞いた。
調べた結果「風景の絵をでこぼこの板 (レリーフ) にはできるが、地面に山や木が立つジオラマ型は作れない」と答え、
ユーザーが「足してほしい」と言った。

## やったこと
- `index.html`: 3 つ目のタブ「風景を作る」(`state.mode === 'scene'`) を追加。
  - 操作: 地形の種類 (`#terrain`: 山と湖 `lake` / 島 `island` / なだらかな丘 `hills`)、「別の風景にする」(`#reroll`)、
    風景の番号 (`#seed`、1〜9999)、山の高さ (`#peak`、4〜40)、水の量 (`#water`、0〜100%)、木の量 (`#trees`、0〜100%)、
    季節 (`#season`: 夏・秋・冬)。広さは既存の「横のマス数」(`#res`、風景の初期値 48) を使う。正方形 N×N。
  - `sceneModel(N)`: 番号を種にした値ノイズ (`hashN` / `vnoise` / `fbm`) で地面の高さを作り、
    水・砂・草・土・石・雪を積み、草の上に木 (広葉樹と針葉樹) を置く。乱数は `Math.random` を使わず、
    番号と座標のハッシュだけで決めるので、同じ番号と設定なら同じ風景になる。
    地形は 0〜1 の座標で読むので、マス数を増やすと同じ地形が細かくなる (木の位置は変わる)。
  - 戻り値は既存の `buildMesh(g, v)` にそのまま渡せる形 (`g.col` は色の一覧、`v.vis` は `[x, 上からの行, z, 色の番号]`)。
    `buildMesh` は変えていない。
  - 「座標データをコピー」(`#copyJson`): 風景のときは `state.grid.scene.vol` から書き出す分岐を足した。形式は今までと同じ `[x, y(上向き), z, 色]`。
  - 風景のタブでは「形」の 3 つのボタン (`#shapeBtns`) と「厚み」(`#thickField`) を隠す。
  - `fitCamera()`: 風景のときだけ、少し高いところから見下ろす向きにした。
  - タブを 2 列から 3 列に。上の説明文に「風景を作ることもできます。」を足した。
- `docs/public/index.md`, `docs/public/index.html`, `guide.html`: 一般向けの説明に「風景を作る」を足した。
- 作業ブランチ `work/landscape`。

## 決めたこと
- **画像から地形を起こす方式ではなく、番号から自動で作る方式にした** (Claude の判断。ユーザーには方式を聞いていない)。
  理由: 「明るさで高さ」は写真の明るさを高さにするだけで、地面・水・木という風景の部品にならない。
  画像を地面として寝かせる案は、高さの地図になる絵を使う人が用意する必要があり、初めての人には難しい。
- 色は彩度を抑えた。ユーザーの好み (ドット絵は子供向けに寄せない) に合わせた。
- 1 マスごとに色を 3 段階 (0.94 / 1 / 1.06 倍) でばらつかせた。水だけはばらつかせない。

## 追記: 水の量と木の量を「広さの割合」に変えた (同じ日)
ユーザーが「水の量と木の量が 100% でなくてもいいの?」「水の量は土地との割合、木は土地の上での割合?」と聞いた。
最初の作りでは、水の量は「水面の高さ ÷ 山の高さ」、木の量は「生えやすさの目盛り」で、広さの割合ではなかった。
「%」と出すなら広さの割合のほうが自然なので、作り直した。

- 水の量: 全マス (N×N) のうち、低いほうから `round(割合 × N × N)` マスを水にする (`wet`)。水面の高さ `wlv` は、
  水になるいちばん高いマスの高さから決める。水のマスは `wlv` 以下に、陸のマスは `wlv + 1` 以上に高さをそろえる。
  上限を 60% から 100% にした (100% は全面が水)。
- 木の量: 草のマスを決まった順 (番号と位置のハッシュ ÷ 林のかたまり具合) に並べ、木の枝の広がり (3×3 マス) が
  草のマスの「割合」ぶんをおおうまで植える (`crown`, `shaded`)。岩・雪・砂には植えない。
  割合を上げても、前からある木はそのままで、新しい木が足される。最後の 1 本で最大 8 マスぶん超えることがある。
- つまみの下に、割合の意味を 1 行で書いた。
- 確認 (書き出した座標データから、各マスのいちばん上のブロックの色を数えた。48 マス・番号 12・夏):
  水 25% → 山と湖 24.5% / 島 25.0% / 丘 24.0%、水 50% → 49.9% / 49.3% / 49.9%、水 100% → どれも 100%、
  水 0%・木 0% → どれも 0%。木 40% → 44.6% / 41.0% / 41.1%、木 20% → 26.1% / 22.5% / 20.9%、木 100% → どれも 100%。
  この数え方は、水や岩の上に張り出した枝も「木」に数えるので、木は多めに、水は少なめに出る
  (水 75%・木 100% のとき、山と湖 69.7% / 島 70.3% / 丘 75.0%)。
- この変更で、初期設定のブロック数は `48×17×48 ・ 20,033 ブロック` になった (下の表の 19,493 などは変更前の数)。
