# 「試してみた」以外のページで、数字・英単語と日本語のあいだの空白を詰める

日付: 2026-11-18 / ブランチ: `work/ja-spacing` (`main` から分けた)

## 目的
ユーザーが「日本語では数字と単位の後ろはあけないことがスタンダード」と言い、「試してみた」の全ページは `work/tried-trees` (コミット 36f22f4) で直した。残りのページ (てびき、マインクラフトに置く、本体の画面、ページの一覧の説明) も同じ決まりで詰める (例:「横 48 マス」→「横48マス」、「Java 版」→「Java版」)。

## 決まり (36f22f4 と同じ)
- 空白を消すのは、英数字・`%` と、ひらがな・カタカナ・漢字・「」、。・ のあいだだけ。
- 変えないもの: 英単語どうし (`Minecraft Wiki`、`px` の前)、`<code>` やバッククォートの前後、かっこ `(` `)` の前後、「1. 風景」の番号のあと。

## やったこと
- `docs/public/index.md`, `index.html`, `minecraft.md`, `minecraft.html`: 正規表現で直した (一時フォルダの `jaspace.py`。`<pre>`・`<script>`・`<style>`・`<code>`・バッククォートの中は先に外してから置きかえる)。300 か所。
- `tools/build_guide.py`: `SUB_PAGES` の `minecraft.html` の説明 (「(Java版)」「1つ」) と、どのページの下にも出るアクセス解析の案内 (「Googleアナリティクス」) を手で直した。`SITE_PAGES` には直す所がなかった。
- 本体 `index.html`: 画面に出る文だけを 1 か所ずつ手で直した (13 か所)。説明文 3 つ (「JSONでコピー」「Java版1.21以降」「Googleアナリティクス」)、表示の数 (`0ブロック`、`…ブロック`、`マス` 3 つ、`色`、「元の画像${nw}」「表示${zoom}%」、「WebPを試して」、「…ブロック分をコピー」)。`<title>` と `meta` の説明文には空白がなかった。
- 本体で、わざと変えなかったもの:
  - 区切りの「 ・ 」(`64×15×9 ・ 3,530ブロック` など)。両側に空白がある区切り記号なので、片側だけ消すと形がくずれる。
  - コマンドの名前の前後 (「/function voxel:break_here で消せます」、保存のあとのお知らせ)。コードの前後は変えない決まりに合わせた。
  - マインクラフトのチャットに出る文 (`tellraw` の「1/3 を置きました」など)。画面の文ではないので、今回の範囲の外にした。
- `python3 tools/build_guide.py` で作り直した。`tried/*.html` 7 つも、アクセス解析の案内の 1 行だけ変わった。`docs/dev/sitemap-dates.json` も更新。
