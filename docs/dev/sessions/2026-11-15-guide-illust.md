# てびきの「できること」「できないこと・注意」に、まとめの図を入れる

日付: 2026-11-15

## 目的
ユーザーが「できること、できないことのところに挿絵がほしい」と言った (`guide.html`)。

## やったこと
1. 最初は、Gemini (`agy` の `image-generator`) の絵を 2 つの節に 1 枚ずつ入れた (ブロックの小さな島、1 個だけ色のちがうブロックの山。Claude の案からユーザーが選んだ)。作業の記録は親フォルダの `ai-collab-workflow/runs/2026-11-15-guide-can-cannot/`。
2. ユーザーが絵を見て「できること、できないことがまとまっている絵にしたい。その中でボクセルを組み合わせていればベスト」と言った。文字の入ったまとめの図なので、CLAUDE.md の分担どおり Claude が SVG で描き直し、Gemini の 2 枚は外した (画像ファイルも消した)。
   - 2 枚の板 (「できること」「できないこと・注意」) を並べた図。各 4 つの項目を、斜めから見たブロック (ボクセル) で描いた。
   - できること: ブロックの「工」の字 (上が橙、下が黄緑) / ブロックのハート / 木と池のある島 / 回る矢印つきの立体。
   - できないこと・注意: ファイルの紙と✕ / 青い山に 1 個だけ橙 / 薄く描いた家と✕ / 高い塔。
   - 色はページの CSS 変数 (`--orange`, `--blue`, `--green` など) を使い、面の暗さは `color-mix()` で付けた。暗い表示でも色が変わる。
   - パソコンの幅では 2 枚を横に、560px 以下では縦に並べる (`.cancan`)。
- 図を作るスクリプト: `tools/cancan_figure.py`。出力の 1 行で `docs/public/index.html` の `<figure class="cancan">` を差し替える。
- `docs/public/index.md` には、ほかのページと同じく「(図: …)」の文で書いた。
- `docs/public/index.html` に図のための CSS を 3 行足した。この `<style>` は `minecraft.html` と `tried/` のページにも前に足されるので、その 6 ページも組み立て直しで変わった (使わない CSS が入るだけ)。
- 下の欄の「挿絵 2 枚は AI (Gemini)。図は Claude」は、元のまま (2 枚に戻した)。
- 作業ブランチ `work/guide-illust`。

## 試してうまくいかなかったこと
- 立体の重なりの順番を「x+y → 高さ」で描いたら、字やハートが前後で崩れた。斜め上から見る図では「x+y+z」の順で描くと正しく重なる。
- 平たい形 (字とハート) は、斜めから見るとゆがんで読みにくい。厚みを 2 にすると、立体らしく読みやすくなった。
