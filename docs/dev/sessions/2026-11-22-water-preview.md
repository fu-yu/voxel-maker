# プレビューに山の上の水を表示する

日付: 2026-11-22

## 目的
ユーザーが「ボクセル工房のプレビューで山からながれる水は表示されない？」と聞いた。2つの案を出した。
- 案1: 流れ終わった形を表示する
- 案2: 流れる様子を動かす

ユーザーは案1を選んだ。案2は作っていない。

## やったこと
- `index.html` の `peakWater()`: 残した峰ごとに `flow()` が求めた水のマス (`f.best` のキー) を集め、`flows` (マスの番号 `(y*N+z)*N+x` の Set) として返すようにした。マインクラフト用の書き出し (`springs`, `ponds`) は変えていない。
- `index.html` の `sceneModel()`: 次の2つがそろうと、`peakWater()` の `flows` と `ponds` を描く (`vis` に `MAT.water` の色で足す)。
  - `#peakWater` がオン
  - 季節が冬でない

  `vol` には書き込まない。そのため、書き出し・座標データ (JSON)・ブロック数の表示は今までと同じ。
- `#peakWater` を切りかえたら描き直す (`'peakWater'` を `schedule` に結ぶ入力の一覧に足した)。
- 画面の注記 `#peakWaterNote` と、説明ページを「画面の立体にも、流れ終わったあとの水を表示する」に直した。説明ページは `docs/public/index.md` / `.html` と `minecraft.md` / `.html`。`python3 tools/build_guide.py` で作り直した。

## 試してうまくいかなかったこと
- 比べるとき、最初は「木の形」を書き出したときと違う設定 (小さな緑の木) にしていたので、数が合わなかった。書き出したときの設定は「マインクラフトの木」。
- ページのスクリプトは `(() => { ... })()` で包まれていて、`state` や `peakWater` をコンソールから呼べない。比べるときは、スクリプトの写しに `window.__dbg={peakWater,sceneModel}` を足して、ページの中で動かした。
