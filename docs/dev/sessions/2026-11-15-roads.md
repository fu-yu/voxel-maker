# 風景に道を入れる (道と家の 1 段目)

日付: 2026-11-15 / ブランチ: `work/roads` (`main` から作成)

## 目的
「風景を作る」に道と家を足す。ユーザーの希望で 1 段ずつ、手元で見てもらってから進める。
1. 道 (この記録) → 2. 家 (箱に三角屋根を数軒) → 3. マインクラフト用の保存で道と家を本物のブロックにし、`voxel:build_slow` / `voxel:break_slow` でも崩れないか見る。

## やったこと
- `index.html`
  - `roadPath(N, gh, wet, wlv, H, top, seed)` を追加。いちばん大きい陸地 (水でない 4 近傍のかたまり) の中で、番号から決まる向き (`hashN(3, 5, seed + 1100)`) の両端にある 2 点を結ぶ。
    - 端点の候補: 石・雪の地面でなく、地図の端から `M = max(2, round(N * 0.1))` マス以上内側のマス (足りなければ条件をゆるめる)。陸が 12 マス未満なら道を作らない。
    - 経路: 4 方向のダイクストラ。状態は「マス × 来た向き」。1 歩の値段 = 1 + 段差 (0:0, 1:2, 2:12, 3 以上:60×段差) + 曲がる 0.4 + 高さ 4×(高さ/(H-1)) + 水 2.5 + ゆらぎ 1.5×`vnoise` + 端に近いほど最大 2。
    - 道のブロックの高さは、陸は地面のいちばん上 (`gh - 1`) を置きかえ、水の上は水面の 1 つ上 (`wlv + 1`) に板を置く (橋)。
  - 材料を 2 つ追加: `MAT.road = 11` (`ROAD.road = '#a08158'`)、`MAT.plank = 12` (`ROAD.plank = '#8b6a45'`)。季節によらず同じ色。
  - 道とその 8 近傍には木を植えない (`near`)。葉が道の上の頭の高さをふさがないようにするため。
  - 「風景」の欄に「道を入れる」のチェック (`#road`、最初はオン) と、説明文に 1 文を追加。
  - `mcBlocks()` の `real` に `dirt_path` と `oak_planks` を足し、秋の葉だけ近い色に置きかえる条件を `m >= 8 && m <= 10` に直した (道と橋が近い色に置きかわらないように)。
- `docs/public/index.md`, `docs/public/index.html`: 「できること」に道の 1 項目、「できないこと」の「家や道はありません」を「地面・水・木と、道 1 本だけ。家はありません」に、更新履歴に 1 行。`python3 tools/build_guide.py` で `guide.html` を作り直した。

## 会話で決まったこと
- 道の色は 3 案 (濃い土色 `#a08158` / 明るい土色 `#c8a774` / 砂利の灰色 `#a9a499`) を画面で撮って見せ、ユーザーが **濃い土色** を選んだ。灰色は石や草にまぎれて道がほとんど見えなかった。明るい土色は水べりの砂と見分けにくい。
- 道は **「道を入れる」のチェックで切り替える** (ユーザーが選んだ)。チェックを外すと、今までとまったく同じ風景になる。いつも出す案は、道の両どなりの木が変わるので採らなかった。
- てびきの「まとめの図」(`tools/cancan_figure.py`、「家や道は作れない」の絵) は `work/guide-illust` にだけあり、`main` に未取り込み。ユーザーの判断で **このブランチでは直さない**。guide-illust の公開後、家 (2 段目) を足すときに「家」と合わせて直す。
- 図の直し方 (ユーザーの考え、2026-11-15): 今の図はしばらくそのままでよい。できるようになったものは、「できないこと」の絵から「できること」の絵へ **移す** 形で直す (消すだけにしない)。

## 試してうまくいかなかったこと
- 最初、`dist` を `Float32Array` にしたら道がほとんどできなかった。heap に入れた値 (倍精度) が `dist` に入れた値 (単精度に丸めたもの) より大きくなり、`c > dist[st]` で取り出した状態を捨ててしまうため。`Float64Array` にして直った。
- 最初の版は端点が地図のへりにあり、道がへりに沿って走って見た目が悪かった。端点を内側に限り、へりに近いマスを高くして直した。
- 標準の視点 (斜め横から) では、手前の木にかくれて道が見えにくい。上から見ればはっきり見える。道の幅 1 マスは依頼どおりなので、そのままにした。
