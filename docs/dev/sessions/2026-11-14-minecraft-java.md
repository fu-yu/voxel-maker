# マインクラフト (Java 版) 用の書き出し

日付: 2026-11-14

## 目的
ユーザーが「マインクラフトで使えるようにしよう」と言った。この Mac で動くのは Java 版だけ (統合版には Mac 用がない) なので、「Java 版で進めて」と決まった。色の置きかえは「近い色のブロックを自動で選ぶ。風景は草・石・水などの本物のブロックにする」(ユーザーの選択)。

## やったこと
- `index.html`
  - 書き出しの欄にボタン `#saveMc`「マインクラフト用に保存」を足した。説明文を 2 つに分け、「マイクラの構造データや 3D ツールへの変換に使えます」の文をやめた。
  - `MC_PALETTE` / `mcNearest(r,g,b)`: コンクリート 16 色・羊毛 16 色・テラコッタ 17 色 (色なしを含む) から、いちばん近い色のブロックを選ぶ (redmean の距離)。
  - `mcBlocks()`: 今の立体を、ブロック名の箱 (`ids`, `names`) にする。文字と画像は色から選ぶ。風景は材料ごとに決める (下の表)。
  - `mcCommands()`: 同じブロックがつながった所を直方体にまとめ、`fill` (1 個のときは `setblock`) にする。座標は `~` の相対。立っている場所から x 方向に 2 マス離して置く (`OX = 2`)。
  - `zipStore(files)` / `crc32`: 圧縮なしの zip を作る (ライブラリなし)。
  - `#saveMc` の処理: `voxel-koubou-datapack.zip` を保存する。中身は `pack.mcmeta` と `data/voxel/function/build.mcfunction`。コマンドが 60,000 行を超えたら `build1`, `build2` … に分ける。
  - `sceneModel()` の戻り値の `scene` に `season` を足した (書き出しで季節を知るため)。
- `docs/public/index.md`, `docs/public/index.html`, `guide.html`: 「試験中」として書き足した。
- 作業ブランチ `work/minecraft-java`。

### 風景のブロックの決め方
| 材料 | 夏・秋 | 冬 |
| --- | --- | --- |
| 草 | `grass_block` | `snow_block` |
| 土・石・砂・雪 | `dirt`, `stone`, `sand`, `snow_block` | 同じ |
| 水 | `water` | `ice` |
| 幹 | `oak_log` | 同じ |
| 針葉樹の葉 | `spruce_leaves[persistent=true]` | 同じ |
| 広葉樹の葉 (3 種) | `oak_leaves` / `birch_leaves` / `oak_leaves` (どれも `persistent=true`)。秋だけは色から近いブロックを選ぶ | 夏と同じ |

- 水がふちにあるマスは、外側にガラス (`glass`) を 1 マス足す。水がまわりに流れ出さないようにするため。このぶん、風景は縦横が 2 マス大きくなる。
- `pack.mcmeta`: `pack_format: 48`, `supported_formats: [48, 9999]`, `min_format: 48`, `max_format: 9999`。1.21 (形式 48) 以降が対象。古い項目は 1.21.9 より前の版のため、新しい項目は 1.21.9 以降のため (Minecraft Wiki の Pack.mcmeta の説明による。「形式 82 より前に対応するなら古い項目も必要」)。
- フォルダ名は `function` (1.21 以降)。1.20 以前は `functions` なので対象外。

## サーバー版での確認 (同じ日の続き)
Microsoft の障害で、ユーザーがサインインの確認コードを受け取れず、ゲームを買えなかった。代わりに、公式の無料のサーバー用プログラムで確かめた (ユーザーが、Java を入れること・ファイルを取ること・利用規約への同意を許可した)。

- 用意: Homebrew で `openjdk@25` を入れた (26.3 は Java 25 が必要。この Mac には Java 8 しかなかった)。サーバーは Mojang の公式の一覧 (`piston-meta.mojang.com` の `version_manifest_v2.json`) から 26.3 の `server.jar` を取り、SHA-1 を照合した。置き場所は作業用の一時フォルダ (リポジトリの外)。
- やり方: 平らな世界 (`level-type=minecraft:flat`) で起動し、RCON でコマンドを送った。`forceload` で場所を読み込み、`execute positioned <位置> run function voxel:build` で置いた。確認用のデータパックを別に作り、書き出したブロック 1 個ずつを `execute unless block` で調べて、ちがう数を数えた。置いた直後と、`tick sprint 2400` (ゲーム内の 2 分) の後の 2 回。
- データパックは、ブラウザの保存の処理を差し替えて、ローカルの受け口に送って取り出した (本体が作る zip そのもの)。

- わかったこと:
  - データパックは起動時に自動で読み込まれ (`Found new data pack file/voxel.zip, loading it automatically`)、関数の読み込みエラーは出なかった。
  - **草ブロックは、真上がふさがれると土に変わる** (木の幹の下、秋の葉に使った色つきブロックの下)。`mcBlocks()` で、真上に葉以外のブロックがある草を、最初から `dirt` にした。
  - 水はガラスの外に出なかった (直す前の書き出しで、まわり 8 マスを調べて 0 個)。落ちるブロックや落とし物もなかった。直した後の書き出しでは、この 2 点の結果を見ていない (水とガラスの処理は変えていない)。
  - 読み込まれていない場所では、`fill` は何も置かない (`That position is not loaded`)。遊ぶ人のまわりは読み込まれているので、ふつうは問題にならない。
- サーバーでは確かめられないこと: 画面での見た目 (色、文字の向き)、パックの番号が合わないときの警告 (サーバーは警告を出さずに読み込む)、26.3 より前の版での動作。

## ゲームの画面での確認 (同じ日の続き)
ユーザーが Java 版を買い、26.3 のシングルプレイで文字と風景 (山と湖・夏) を置いて、スクリーンショットを 2 枚送ってくれた。

- 読み込みと実行: チャットに「再読み込み中...」「関数「voxel:build」を実行中です」と出た。赤い文字はなし。
- 風景: 石・土・草・砂・雪・木が置かれ、角の水はガラスの中におさまっていた。葉も残っていた。横の面は石と土の断面が見える (ジオラマの側面)。ガラスは枠の線が見える。
- 文字: 上が橙、下が黄緑で、上下は正しい。濁点のある字が左端にあり、濁点は右上なので、裏返しではない。
- **見つかった問題**: 文字のグラデーション (橙 `#f08a3c` → 黄緑 `#8fbf5a`) の途中に、灰色 (`light_gray_wool`) の帯が入った。
  - 原因は色の値ではなく、選び方。ゲームのファイル (ユーザーの Mac に入った 26.3 の絵柄) から 49 種類の平均の色を計算したら、今の値との差は最大 1 だった (ずれていた 2 つを直した)。
  - 近さの計算を、RGB の重みつきの距離 (redmean) から **OKLab** の距離に変えた (`okLab()`, `MC_LAB`)。同じグラデーション 15 段で試すと、redmean は「橙 2 → 黄テラコッタ 9 → 灰 2 → 黄緑 2」、OKLab は「橙 4 → 黄テラコッタ 6 → 黄緑 5」。明るさの重みを 0.5、0.25 に下げた案も試したが、1.0 (そのまま) がいちばんむらがなかった。
  - 直したあと (ローカルで書き出しを調べた): 文字は `orange_wool` 387・`yellow_terracotta` 1,972・`lime_wool` 1,171 で灰色なし。見本の画像は `orange_wool`・`orange_concrete`・`white_wool`・`white_terracotta`・`yellow_concrete`。秋の葉は `orange_concrete`・`pink_terracotta`・`yellow_concrete`・`yellow_terracotta`。
- 直したあとの見た目は、ゲームの画面では **未確認**。見本の画像の軸に `yellow_concrete` (あざやかな黄) が 70 個入るので、浮いて見えるかもしれない。
