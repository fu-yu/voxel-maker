# 座標データの説明の項目を英数字にする

日付: 2026-11-14

## 目的
ユーザーが、コピーした座標データ (JSON) に日本語が入っていることに気づいた。マインクラフトでも使えるようにしたいので、まず日本語で出力しているところを直す、と決めた。

## やったこと
- `index.html` (`#copyJson` の処理): 書き出す JSON の `format: '[x, y(上向き), z, 色]'` をやめ、`order: ['x', 'y', 'z', 'color']` と `up: 'y'` にした。`size` と `voxels` は変えていない。
  - 理由: `format` は人が読むための文で、プログラムからは使えなかった。Windows で文字の決まりを指定せずに読むと、文字化けやエラーになるおそれもあった。
- 作業ブランチ `work/json-ascii`。

## マインクラフト向けの書き出しの下調べ (未実装)
ユーザーは「マインクラフトで使えるようにしよう」と言った。どの版向けかは **まだ決まっていない**。色の置きかえは「近い色のブロックを自動で選ぶ。風景は草・石・水などの本物のブロックにする」と決まった。

| | Java 版 | 統合版 |
| --- | --- | --- |
| 入れ物 | データパック (`pack.mcmeta` が必須) | ビヘイビアーパック (`manifest.json`。`uuid` と `min_engine_version` が要る) |
| 読み込み | `/function` (コマンドの一覧)、`/place template` (構造データ `.nbt`) | `/structure load <名前> <位置>` |
| 上限 | 関数は 65,536 コマンドまで (`max_command_sequence_length`)。`/fill` は 32,768 ブロックまで (`max_block_modifications`) | 構造データは 64×384×64 より小さいこと |
| 版ごとのちがい | パックの番号が版ごとに変わる (1.20 = 15、1.21 = 48、1.21.9 = 88、26.3 = 121)。1.21 でフォルダ名が `functions` → `function`、`structures` → `structure`。1.21.9 から `pack_format` の代わりに `min_format` / `max_format` | 小さい |

- 出典: Microsoft Learn (統合版の `/structure`、構造ブロックの手引き、マニフェストの説明)、Minecraft Wiki (Java 版の Pack format、Function、Commands/fill)。Java 版には公式の手引きが見つからず、wiki を使った。
- 確かめられなかったこと: 統合版の `.mcfunction` の決まり (公式ページが 404)、統合版で `.mcstructure` を置くフォルダ、Android での取り込み方、Java 版でコマンドで置いた葉が消えるか (`persistent=true` を付ければ安全)、`/place template` の大きさの上限。
- 実際のマインクラフトでの動作は、Claude からは確かめられない。ユーザーが持っている版で試してもらう必要がある。
