# 「建てる係」つきで少しずつ置く (`voxel:build_slow`)

日付: 2026-11-14

## 目的
マインクラフト用のデータパック (`voxel-koubou-datapack.zip`) に、小さな生き物 (アレイ) が建てる係として飛び回りながら、下の段から少しずつブロックを置く `/function voxel:build_slow` を足す。設計と小さな試し用のデータパックでの確認は `docs/dev/builder-design.md` で済んでおり、その続きとして本体への組み込みと照合、ゲームの画面での確認を行う。

## やったこと
- `index.html`
  - `mcSteps(B)` を追加した。ブロックを下の段 (`y = 0`) から順に並べ、各段の中では水以外を先に、水を最後に置く。`z` ごとに `x` の向きを往復させ、最大 1,200 段階 (`N = max(1, min(1200, ceil(total / 4)))`) に均等に分ける。各段階の真ん中のブロックの位置 `mid` も返す。
  - `mcCommands(B, stepOf)` を拡張した。`stepOf` があるときは、同じブロックかつ同じ段階のマスだけを直方体 (`fill` / `setblock`) にまとめ、段階ごとの配列として返す。引数がないときは従来どおり 1 つの配列を返す。
  - `mcBlocks()` で、空中で風景を置いたときにも砂が落ちて底が抜けたりガラスの下から水が漏れたりしないよう、1 段目 (`y = 0`) の砂を `stone` に変え、ふちの水の外側 (`k = 1..y`) の最下段 (`k = 1`) に `stone`、その上に `glass` を置くようにした。
  - `#saveMc` の書き出しに `data/minecraft/tags/function/tick.json`, `load.json`, `data/voxel/function/build_slow.mcfunction`, `build_stop.mcfunction`, `slow/load.mcfunction`, `slow/tick.mcfunction`, `slow/next.mcfunction`, `slow/ready.mcfunction`, `slow/run.mcfunction`, `slow/done.mcfunction`, `slow/stop.mcfunction`, `slow/bye.mcfunction`, `slow/s0.mcfunction`〜`s(N-1).mcfunction` を足した。保存後の通知にも `voxel:build_slow` を案内する文を入れた。

### ゲームの画面での確認 (Java 版 26.3、シングルプレイ)
ユーザーが `/tmp/voxel-mc/packs/gen_lake_max.zip` (風景・山と湖・夏、横 128 マス・高さ 40 マス) を `/function voxel:build_slow` で置き、スクリーンショットを 6 枚撮った。
- 地上で実行したとき: 下の段から 1 段ずつ石・砂・土が広がり、各段の最後に水とガラスが置かれた。アレイと白い粒 (`end_rod`) も確認できた。中腹から山頂の雪まで順番に積み上がり、「できあがりました」と表示されて完成した。水もガラスの中におさまっていた。
- 空中で実行したとき (直す前): 浮いた位置から建ちはじめ、1 段目の砂が落ちて隙間ができ、ふちのガラスの下にもブロックがなかったため、水が地面へ流れ出した。
  - 直し: `mcBlocks()` で `y === 0` の砂を `stone` に変え、ふちの水の外側も `k = 1` に `stone`、`k = 2..y` に `glass` を置くようにした。
  - 直したあと: `datapacks` フォルダに古い zip が名前を変えて残っていると古いほうが読み込まれることがわかり、古い zip を消して `/reload` したあと空中で実行したところ、底がすべて石で埋まり、砂も水も落ちずに置けることをゲームの画面で確認した (`mc-slow-fixed.jpg`)。
