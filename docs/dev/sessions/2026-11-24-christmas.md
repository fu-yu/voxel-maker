# 風景の季節に「クリスマス」を足す

日付: 2026-11-24 / ブランチ: `work/christmas`

## 目的
ユーザーの依頼「クリスマス近いから木をクリスマス仕様にしたい」(ほかのセッションから伝わった)。作る前に 3 つ聞いた。
- いつ出すか: 「季節に『クリスマス』を足す」(ユーザーの選択。冬に切りかえを足す案と、冬をクリスマスにする案は選ばれなかった)
- 飾り: てっぺんの星・電飾 (光る玉)・雪・木の下のプレゼントの 4 つ全部
- 飾る木: 針葉樹だけ (丸い木は冬と同じ、雪をかぶった木のまま)

## やったこと
- `index.html`:
  - 季節の選択に「クリスマス」(`xmas`) を足した (冬の次)。
  - `SEASONS.xmas` は `SEASONS.winter` と同じ色に `xmas: true` を付けたもの。
  - `MAT` に `star: 17`、`light: 18`(〜21)、`present: 22`(〜24) を足した。色の表 `DECOR` を `mats` の後ろに足した。`mcBlocks()` の `real` に次を足した。
    - 星: `glowstone`
    - 電飾: `ochre_froglight` / `verdant_froglight` / `pearlescent_froglight` / `shroomlight`
    - プレゼント: `red_wool` / `blue_wool` / `yellow_wool`
  - クリスマスは、書き出しで冬と同じ扱い (`winter` を真にする)。草は `snow_block`、水は `ice`。
  - `leafAt` が、記録中 (`rec`) なら置いた葉の位置を集める。針葉樹 (小さな緑の木・マインクラフトの木の両方) を植えるときに集め、植え終わったら `decorate()` で飾る。飾り方は次のとおり。
    - 外に面した葉 (となり 4 つのどれかが空き) の 14% を電飾 (4 色のどれか) にする。
    - 上が空いている葉の 40% を雪にする。
    - 幹の真上でいちばん高い葉の 1 つ上に星を置く。
    - 幹のとなり 4 マスのうち 1〜2 マスに、地面の高さが同じで空いていればプレゼント (3 色) を置く。
    - どれも `hashN` で決めるので、同じ番号なら同じ飾りになる。
- 色: ゲームのクライアント (26.3) の絵の平均で計算した。
  - 羊毛はそのまま使った: 赤 #a12723、青 #35399d、黄 #f9c628。
  - 光るブロックは平均が白っぽい (例 `ochre_froglight` の横の面 #f5e9b6、`glowstone` #ac8354)。画面では「光っている」と見えるよう、少し明るく色を付けた: 星 #f3cf5a、電飾 #f2d46b / #9fd89a / #e8b9e2 / #f19347。
- 前に一時フォルダに置いていた道具 (ほどき用のスクリプトや `rcon.py`、`recv.py`) と、サーバーの `server.jar` は、一時フォルダの片づけで消えていた。`recv.py` と `rcon.py` は書き直した。サーバーは置き直していない。
- 説明ページ:
  - `docs/public/index.md` / `.html`: 季節の文にクリスマスを足し、更新履歴に 2026-11-24 の行を足した。
  - `docs/public/minecraft.md` / `.html`: 表の見出しを「冬・クリスマス」にし、飾りのブロックの注を足した。
  - `python3 tools/build_guide.py` でページを作り直した (`sitemap.xml` と `docs/dev/sitemap-dates.json` の日付も更新された)。
- `work/spring` に残っていた記録 (春の地面の花など、まだ `main` に入っていなかった分) も、このブランチに取り込んだ。

### ゲームの大きなトウヒ (サーバー版 26.3)
- `worldgen/feature/mega_spruce.json` を読んだ。
  - 幹: `giant_trunk_placer` (`base_height` 13、`rand_a` 2、`rand_b` 14)
  - 葉: `mega_pine_foliage_placer` (`radius` 0、`crown_height` 13〜17)
- `tools/mc/probe_tree.py minecraft:mega_spruce 3 6 33` で 3 本を読んだ。
  - 幹は 2×2 で、高さ 18〜24。
  - 葉は、幹のまわりの円の段。数は 8 / 20 / 40 / 64 (半径 1〜4、2×2 の幹を中心に数える)。
  - 段の半径は上から 0 → 下で 3 まで広がり、ところどころ 1 つ広い段がまじる。
- 作り方の式は、`floor(上からの深さ / 葉の段数 × 3.5)` で、偶数の段でひとつ前と同じなら +1。この式で、読みとった各段の葉の数 (8・20・40・64) と同じになることを数えて確かめた。

- `index.html`:

  - 画面: `buildMesh()` で、風景の電飾の立体を 2 組に分け、0.5 秒ごとに交互に、電飾の色と針葉樹の葉の色にぬりかえる (`blinkTimer`)。「動きを減らす」の設定の人には点滅しない。

## 続き: 電飾をレッドストーンランプにした (同じ日)
- ユーザーの指示「Webでマイクラの電飾について調べてみて」。調べてわかったこと:
  - よく使われる電飾は、ランタン (葉の下につり下げる)、レッドストーンランプ (回路で点滅)、銅の電球、シーランタン、ろうそく。
  - 点滅は、レッドストーン回路で点け消しするのがふつう。データパックで点滅させる例は見つからなかった。
  - 公式の記事「Treemendous decorations」は、読みに行ったが 2 回とも時間切れで読めなかった。
- そのあとのユーザーの指示「レッドストーンランプで試してみて」。サーバー版 26.3 で試した結果:
  - `setblock ... redstone_lamp[lit=true]` で置くと、電気がなくても点いたまま (20 tick 後も点灯)。
  - ただし、となりのブロックがふつうに置きかわると消える (例: となりに葉を置く、となりのランプを消す)。
  - `setblock ... strict` (まわりに知らせない置き方) で、となりのランプを点け消ししても、点いたまま。2 つのランプを交互に 6 回入れかえても、正しく入れかわった。
  - プレイヤーがとなりにブロックを置くと消えるが、次の点滅 (0.5 秒以内) でまた点く。
  - 比べるために試した `waxed_copper_bulb[lit=true]` は、となりが変わっても点いたままだった。
- `index.html`:
  - 電飾 (`MAT.lightA` / `lightB`) の書き出しを、すべて `redstone_lamp[lit=true]` にした。
  - 点滅の `voxel:xmas/a` と `voxel:xmas/b` は、片方の組を `redstone_lamp[lit=true] strict`、もう片方を `[lit=false] strict` にする。前は「光るブロック ⇔ 葉」の入れかえだったので、消えている電飾が見えなかった。
  - 画面の色: 点いたランプは #f2c26b (絵の平均 #8f663d より明るくした)、消えたランプは絵の平均 #5f371e (`MAT.lampOff` 28)。
- 説明ページ (`minecraft.*`): 電飾をレッドストーンランプにし、「点いたり消えたり」に直した。

## 続き: 参考の写真に寄せて、すそ広がりのツリーとランタンにした (同じ日)
- ユーザーが「こんな雰囲気がいいのです」と、ブログの記事 (2019 年 12 月、マインクラフトのクリスマスツリーの写真 3 枚) を見せた。写真から読みとったこと:
  - 形: 平たい段が何層も重なる、すそ広がりの円すい。
  - 電飾: 小さな暖かい黄色の灯りが、段のふちにたくさん付いている。
  - 星: てっぺんに 1 つ。
  - まわり: ひらけた雪原に 1 本だけ立っている。
  - 記事の本文は 3 文だけで、使ったブロックの名前は書かれていなかった。写真はブラウザのペインで開いて見た。
- 直し方を 3 つ出した (形・ランタンの電飾・まわりをあける)。ユーザーの答えは「全部取り入れて」。ランタンは点滅できないので、ランタン (ずっと灯る) と、段の内側の点滅するランプをまぜた。
- サーバー版 26.3 で試した結果:
  - ランタンは、葉 1 つの上に置くと 20 tick たっても落ちない。葉の下につり下げても落ちない。
  - ふつうの `fill ... air` で下の葉を消すと、ランタンが落とし物になる。`fill ... air strict` なら落ちず、落とし物も出ない。
  - しかし、ツリーに組み立てると、置いた直後の 53 個のうち、1 tick 後には 20 個に減った (28 個が落とし物)。ゲームが葉の「幹からの距離」(distance) を数え直して書きかえると、そのお知らせで、上のランタンが「葉の上には立てない」と判定されて落ちたと考えられる。1 つだけで試したときは近くに幹がなく、葉の状態が変わらなかった。
  - ランタンの真下を、トウヒの原木 (枝の先に見える) にしたところ、53 個すべて残った (3 秒後・13 秒後)。
- `index.html`:
  - `bigTree()` を書きかえた。幹 2×2、葉は 15〜18 段。3 段ずつの組で、1 段目は広い平たいふち (半径 R)、2・3 段目は R−1.5、R−2.5 とすぼまる。R は組ごとに、下の 6〜7 から上の 1 まで小さくなる。
  - ふち (1 段目のいちばん外側) の 32% に「原木 + その上にランタン」(`MAT.lantern` 29、色 #ffcf66)。ふちの残りの 30% には薄い雪をのせる。
  - 段の内側の外に面した葉の 14% を、点滅するレッドストーンランプにした (2 組)。
  - ほかの木は、ツリーから 10 マス以内に植えない (前は 5 マス)。
  - 書き出しの `real` に `lantern` を足した。ランタンがあるデータパックだけ、消すコマンド (`voxel:break`、`break_here` の `clear/c*`、`break_slow` の段) に `strict` を付ける (`mcCommands()` の 4 つ目の引数 `mode`)。
- 説明ページ (`index.*`、`minecraft.*`) を、すそ広がりのツリー・ランタン・点滅ランプに書き直した。
