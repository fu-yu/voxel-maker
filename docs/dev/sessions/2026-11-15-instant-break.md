# 一気に消す `voxel:break` と、壊す係が止まる不具合の直し

日付: 2026-11-15 / ブランチ: `work/instant-break`

## 目的
ユーザーから「break_slow で 1 が戻るエラーが続いている」と報告があった。原因を調べて説明したあと、直し方を 3 案示した (一気に消す / 止まったときに直す / 置く前の景色に戻す)。ユーザーは「すぐ元通りにできる機能の実装の方がいい」と言い、`voxel:break` (一気に消す) を選んだ。

## 原因 (ゲームのログとワールドの保存データから)
- ユーザーのゲームのログ (`logs/latest.log`) で、`voxel:break_slow` を始めたあと、終わる前に `voxel:build` を打っていた (08:26 と 08:37)。
- `voxel:build` は目印 (`marker`、タグ `voxel_site`) を消して作り直す。新しい目印には `voxel` の点数がない。そのため次の tick で `slow/bnext` の 1 行目 (`execute unless score @s voxel = #run voxel run return run kill @s`) が新しい目印を消す。
- その結果、目印がなくなり、`#on` が 2 (壊している途中) のまま残る。`voxel:break_slow` は 2 行目の確かめで「いま壊しているところです」と出して `return run tellraw` で止まり、ゲームには「戻り値 1」と出る。
- ワールドの `data/minecraft/scoreboard.dat` (08:38 の保存) では `#on` = 2、`#i` = 749 だった。壊す処理そのものは 749 段まで動いていた。
- サーバー版 26.3 で、「build → break_slow → build」の順に打つと、目印が消えて `#on` が 2 のまま残ることを再現した。

## やったこと
- `index.html` の保存の処理: `voxel:break` を足した。データパックの中身は次のとおり。
  - `clear/c<i>.mcfunction`: `mcCommands(B, null, true)` (空気で埋めるコマンド)。6 万行ごとに分ける。分かれたときは `voxel:break1`〜`N` になる (`voxel:build1`〜`N` と同じ)。
  - `break.mcfunction`:
    - 動いている係を止める (`#on` が 1 なら `slow/stop`、2 なら `slow/bstop`)。
    - 目印がなければ「消す立体の目印が見つかりません…」と出して終わる。
    - `execute at <いちばん近い目印> run function voxel:clear/c<i>` で消す。
    - 最後の部分で目印を消し、「消しました」と出す。
- `voxel:build` の 1 つ目のファイルの最初に、同じ「動いている係を止める」2 行を足した。壊している途中で `voxel:build` を打っても、目印が消されず、止まったままにならない。
- 保存したときのお知らせ (toast) に `voxel:break` を足した。
- `docs/public/minecraft.md` / `.html`: 次を直した。`python3 tools/build_guide.py` でページを作り直した。
  - 手順 7 に `voxel:break` を足した。
  - 「一気に消す」の節を足した。
  - 「少しずつ壊す」の節に、途中で `voxel:build` を打つと止まることを足した。
  - 「置く前に知っておくこと」に `voxel:break` を足した。
  - 「うまくいかないとき」に「いま壊しているところです」と出たときの直し方を足した。

## 確認したこと / していないこと
| 項目 | 状態 |
| --- | --- |
| build のあと break で消える | 確認済み。サーバー版 26.3 (RCON) で、秋の風景 (山と湖・48 マス) を置き、立体から 30 マス上・20 マス横の位置で `voxel:break` を打った。置いた範囲の 26 段がすべて空気になった。確かめ方は、各段を空の高さ (y=200) の同じ広さと `execute if blocks ... masked` で比べた。真下の地面の草は残り、落ちるブロック・落とし物は 0 |
| build → break_slow → build → break | 確認済み (同じやり方)。2 回目の build のあと `#on` = 0、目印 1 個、壊す係 0。そのあと break ですべて空気になった |
| 2 回目の break | 確認済み。「目印が見つかりません」で終わる (戻り値 0) |
| 6 万行をこえて `break1`〜`N` に分かれる場合 | **未確認** (いちばん大きい設定では試していない) |
| ゲームの画面 | 確認済み (2026-11-15、ユーザー)。ゲームのログでは次のとおり。目印がない状態で `voxel:break` を打つと「消す立体の目印が見つかりません…」(戻り値 1)。`/reload` のあとの `voxel:break_stop` は「いまは壊していません」。`voxel:build` のあとの `voxel:break` は「消しました」。ユーザーが「消えました」と報告した |
| 説明ページの表示 | 確認済み (ローカルで、デスクトップ幅と 375px 幅) |

## 試してうまくいかなかったこと
- はじめは `voxel:break` だけを足した。しかし、止まった状態では目印がもう消えているので、`voxel:break` も消す場所がわからなかった (サーバーで確認)。そこで、`voxel:build` が先に係を止めるようにした。
- 今のユーザーのワールドは、すでに目印がない。`voxel:break_stop` を打ってから、置き直して (`voxel:build`) 消す必要がある。
