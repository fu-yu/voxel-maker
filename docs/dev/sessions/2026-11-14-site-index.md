# すべてのページにつながる一覧

日付: 2026-11-14

## 目的
ユーザーが「全てのページにつながるインデックスがほしい」と言った。ページが 4 つ (本体、てびき、マインクラフトに置く、マインクラフトで試してみた) に増えたため。

## やったこと
- `tools/build_guide.py`: ページの一覧 `SITE_PAGES` (ファイル名・名前・ひとことの説明) を足した。`add_site_nav()` が、作るページすべてに次の 2 つを入れる。
  - 上: 短い一覧 (`<nav class="sitenav">`)。今のページは `aria-current="page"` で色を変える。
  - 下: 説明つきの一覧 (`<section class="siteindex">`「ページの一覧」)。今のページは出さない。
  - **ページを足すときは、`SITE_PAGES` に 1 行足すだけで、どのページの一覧にも出る** (`SUB_PAGES` と `deploy.yml` の `cp` の行にも足すこと)。
- `docs/public/minecraft.html`, `docs/public/tried.html`: 上にあった個別のリンク (`.back`) を消した (一覧と重なるため)。
- `index.html` (本体): 左の欄のいちばん下に「ページの一覧」の欄を足した (てびき・マインクラフトに置く・マインクラフトで試してみた)。こちらは手で書いてあるので、ページを足したらここも直す。
- 一覧は組み立てのときに入るので、`docs/public/` の本文 (Artifact 用) には入らない。
- 新しいページは足していないので、`deploy.yml` は変えていない。
- 作業ブランチ `work/site-index`。

## 決めたこと
- 一覧だけの新しいページは作らず、すべてのページに共通の一覧を入れる形にした (Claude の判断。新しいページを作ると公開の設定の変更が要り、たどる手数も増えるため)。ユーザーが一覧だけのページをほしいと言ったら、足す。
