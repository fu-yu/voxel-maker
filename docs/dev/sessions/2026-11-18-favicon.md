# 全ページにアイコン (favicon) をつける

日付: 2026-11-18 / ブランチ: `work/favicon`

## 目的
ブラウザのタブやブックマークに出るアイコンを、サイトの全ページ (本体と、`tools/build_guide.py` が作る 8 ページ) につける。

## 絵柄の選び方 (ユーザーと決めたこと)
- 案を 3 つ SVG で作って見せた: A 1 つの立方体に線を入れて 2×2×2 の小さなブロックに見せる形 / B ブロックを 3 つ積んだ形 / C 四角を正面の階段に並べた形。どれもサイトのオレンジ (`#f5a05a` 上の面、`#ad4c0b` 左の面、`#7a3407` 右の面)。
- **ユーザーは A を選んだ。** 16px では線がほぼ見えず、ただの立方体に見える (案を見せるときに伝えた)。
- 既存のゲームを連想させないよう、草ブロックのような緑と茶の組み合わせは使っていない。

## やったこと
- `docs/public/images/favicon.svg` を足した (viewBox 64×64、背景は透明。多角形 3 つと、生成り色 `#fffaf0`・不透明度 0.55 の線 6 本)。等角の立方体を Python で計算して書いた。
- `docs/public/images/apple-touch-icon.png` を足した (180×180、5KB)。iPhone のホーム画面用。透明だと黒く埋められるので、背景を生成り色 `#f1e7cd` にして周りに余白をとった。作り方: SVG の viewBox を `-14 -14 92 92` に広げて背景の四角を足し、ヘッドレス Chrome (`--window-size=180,180 --screenshot`) で撮った。
- 置き場所を `docs/public/images/` にしたので、`.github/workflows/deploy.yml` は変えていない (そのフォルダごと公開している)。
- `index.html`: `<link rel="canonical">` の下に `<link rel="icon" … type="image/svg+xml">` と `<link rel="apple-touch-icon">` の 2 行を足した。
- `tools/build_guide.py`: 共通の `HEAD` に同じ 2 行を足した。`build_sub()` で、`tried/` の中のページでは `href="docs/public/images/` を `href="../docs/public/images/` に置きかえる。
- `python3 tools/build_guide.py` で 8 ページと `sitemap.xml` を作り直した。ページの中身が変わったので、`sitemap.xml` の更新日は全ページ 2026-11-18 になった (`docs/dev/sitemap-dates.json` もコミット)。
