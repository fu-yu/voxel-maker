# マインクラフトで試してみた

## ひとことで言うと

ボクセル工房で作った立体を、本物のマインクラフトに置いて確かめた記録です。
うまくいったことも、見つけた問題も、そのまま書いています。

## 試した環境

- マインクラフト Java 版 26.3 の、ひとりで遊ぶモードです。
- 平らな地面だけのワールド (スーパーフラット) に置きました。
- 試した日は 2026-11-14 です。
- 置き方は「[マインクラフトに置く](https://fu-yu.github.io/voxel-maker/minecraft.html)」のページのとおりです。

## 試した記録

3 つの記録を、それぞれ別のページに分けています。

1. **[1. 風景を置いてみた](https://fu-yu.github.io/voxel-maker/tried/scene.html)**
   「山と湖・夏」の風景を、上から・横から・角から・夕方の 4 つの見え方で確かめた記録です。(写真 4 枚)
2. **[2. 文字を置いてみた](https://fu-yu.github.io/voxel-maker/tried/text.html)**
   文字の立体を置いて、向きと色の出方を確かめた記録です。(写真 1 枚)
3. **[3. 少しずつ置いてみた (`voxel:build_slow`)](https://fu-yu.github.io/voxel-maker/tried/slow.html)**
   いちばん大きい設定の風景を、建てる係 (アレイ) つきで下の段から少しずつ置いた記録と、空中で置いたときの水漏れを直した記録です。(写真 6 枚)

## 見つけて直したこと

| 見つけたこと | 直し方 |
| --- | --- |
| 木の幹の下の草が、時間がたつと土に変わった | はじめから土を置くようにした |
| 文字の色分けに、灰色がまじった | 近い色の選び方を、人の目の感じ方に近い方法に変えた |
| 空を飛んだ状態で風景を置くと、1 段目の砂が落ちてふちの水も下から漏れた | 1 段目の砂を石にし、ふちのガラスの下端にも石を置くようにして、空中で置いても漏れないことを確かめた |

## 試すときのこつ

- 空を飛ぶと、上から全体を見られます。クリエイティブモードで、スペースのキーを 2 回すばやく押します。下がるときは左の `shift` キーを押します。
- 写真は、マインクラフトのスクリーンショットの機能で撮りました。ノート型の Mac では、はじめのキー (F2) がそのままでは効きませんでした。マインクラフトの「キー割り当て」で、別のキーに変えると撮れました。

## これから試すこと

- 歩きやすい設定 (なだらかな丘、横 128 マス、山を低め) で置いて、歩いてみる。
- 風景を少し下にずらして置き、まわりの壁を低くする。
- 色の選び方を直したあとの文字を置く。
- 秋と冬の風景、島と丘の地形を置く。
