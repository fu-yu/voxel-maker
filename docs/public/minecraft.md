# マインクラフトに置く

## ひとことで言うと

ボクセル工房で作った立体を、マインクラフトのワールドに置くための手順です。
保存したファイルをワールドに入れて、コマンドを 1 つ打つと、立っている場所のとなりに立体が置かれます。

(図: 保存する → ワールドに入れる → コマンドで置く、の 3 コマ)

## 使えるマインクラフト

- パソコンの「Java 版」の 1.21 以降で使えます。動きを確かめたのは 26.3 です。
- スマホ、ゲーム機、Windows の「統合版」では使えません。
- コマンドを使うので、「チートの許可」がオンのワールドが必要です。

## 手順

1. [ボクセル工房](https://fu-yu.github.io/voxel-maker/)で、置きたい立体を作ります。
2. 左の欄のいちばん下にある「マインクラフト用に保存」を押します。`voxel-koubou-datapack.zip` というファイルが保存されます。
3. マインクラフトを開き、置きたいワールドを選んで「編集」を押し、「ワールドフォルダーを開く」を押します。
4. 開いたフォルダの中の `datapacks` フォルダに、保存したファイルを入れます。ファイルは開かずに、そのまま入れます。
5. ワールドに入り、立体を置きたい場所に立ちます。
6. チャットの欄に `/reload` と打ちます。
7. 続けて `/function voxel:build` と打ちます。

手順 3 と 4 は、Minecraft Wiki の「[データパックの読み込み](https://ja.minecraft.wiki/w/チュートリアル:データパックの読み込み)」の説明によります。Minecraft Wiki は、公式のサイトではありません。

## どこに置かれるか

(図: 上から見た図。立っている場所の 2 マス東に立体の角があり、東と南に向かって置かれる)

- 立っている場所の 2 マス東が、立体の角になります。そこから東・南・上に向かって置かれます。立っている場所との間は、1 マスあきます。
- 高さは、足もとの高さから上です。
- 大きさは、ボクセル工房の画面の左下に「48×17×48」のように出ています。順に、東西・高さ・南北のマスの数です。
- 風景は、まわりに 1 マスずつ広くなります。水をせき止めるガラスを置くためです。
- 文字は、南側に立って北を向くと読める向きに置かれます。

## 置く前に知っておくこと

- 立体が置かれる場所にもとからあったブロックは、置きかえられます。建物のそばでは実行しないでください。
- 置いたあとで元に戻す機能はありません。はじめは、新しいワールドか、何もない場所で試すのがおすすめです。
- 広くて平らな場所が向いています。ワールドの種類を「スーパーフラット」にすると、見やすくなります。

## 何のブロックになるか

文字と画像の立体は、色のそろった 49 種類のブロック (コンクリート・羊毛・テラコッタ) から、いちばん近い色のものになります。画面とまったく同じ色にはなりません。

風景は、次のブロックになります。

| 画面の見た目 | 夏・秋 | 冬 |
| --- | --- | --- |
| 草 | 草ブロック | 雪ブロック |
| 土・石・砂・雪 | 土・石・砂・雪ブロック | 同じ |
| 水 | 水 | 氷 |
| 木の幹 | オークの原木 | 同じ |
| とがった木の葉 | トウヒの葉 | 同じ |
| 丸い木の葉 | オークの葉・シラカバの葉 (秋は、近い色のブロック) | オークの葉・シラカバの葉 |

- 水がふちにある所には、外側にガラスを置きます。水がまわりに流れ出さないようにするためです。
- 木の幹の下などの、上がふさがれた草は、土にしてあります。マインクラフトでは、そうした草は時間がたつと土に変わるためです。
- 葉は、時間がたっても消えない設定で置かれます。

## うまくいかないとき

- **「関数が見つからない」という意味の赤い文字が出る**: ファイルが `datapacks` フォルダに入っているか、`/reload` を打ったかを確かめます。ファイルを開いて中身だけを入れた場合は、開く前のファイルを入れ直します。
- **コマンドが使えない**: ワールドの「チートの許可」がオフになっています。
- **立体の一部が置かれない**: 遠くの土地がまだ読み込まれていないと、そこには置かれません。大きな立体で起きやすくなります。マスの数を減らして、作り直してみてください。

## 確かめたこと・まだのこと

- マインクラフト 26.3 で、文字・画像・風景 (3 つの地形、3 つの季節、いちばん大きい設定) を置きました。どれも、すべてのブロックが正しく置かれ、ゲームの中の 2 分後もそのまま残りました (2026-11-14)。この確認は、画面のないサーバー用のマインクラフトで行いました。
- ゲームの画面での見た目 (色の近さ、文字の向き) は、まだ確かめていません。
- 1.21 から 26.2 までの版では、まだ試していません。

## ことばの説明

- **Java 版・統合版**: マインクラフトには 2 つの種類があります。Java 版はパソコン用です。統合版は、スマホ・ゲーム機・Windows 用です。
- **データパック**: マインクラフトのワールドに、あとから足せるファイルのこと。
- **コマンド**: チャットの欄に打ちこむ命令のこと。`/` から始まります。
- **ワールド**: マインクラフトで遊ぶ世界 1 つ分のこと。
