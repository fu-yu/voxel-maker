# マインクラフトに置く

## ひとことで言うと

ボクセル工房で作った立体を、マインクラフトのワールドに置くための手順です。
保存したファイルをワールドに入れて、コマンドを1つ打つと、立っている場所のとなりに立体が置かれます。

(図: 保存する → ワールドに入れる → コマンドで置く、の3コマ)

## 使えるマインクラフト

- パソコンの「Java版」の1.21以降で使えます。動きを確かめたのは26.3です。ただし、秋の風景は26.3以降でだけ使えます (ポプラの葉を使うため)。
- スマホ、ゲーム機、Windowsの「統合版」では使えません。
- コマンドを使うので、「チートの許可」がオンのワールドが必要です。

## 手順

1. [ボクセル工房](https://fu-yu.github.io/voxel-maker/)で、置きたい立体を作ります。
2. 左の欄のいちばん下にある「マインクラフト用に保存」を押します。`voxel-koubou-datapack.zip` というファイルが保存されます。
3. マインクラフトを開き、置きたいワールドを選んで「編集」を押し、「ワールドフォルダーを開く」を押します。
4. 開いたフォルダの中の `datapacks` フォルダに、保存したファイルを入れます。ファイルは開かずに、そのまま入れます。
5. ワールドに入り、立体を置きたい場所に立ちます。
6. チャットの欄に `/reload` と打ちます。
7. 続けて `/function voxel:build` と打ちます。置き終わると、チャットに「できあがりました (置いた場所: 座標) [消す]」と出ます。少しずつ置きたいときは、代わりに `/function voxel:build_slow` と打ちます。置いた立体を壊して消したいときは、`/function voxel:break_slow` (少しずつ) か `/function voxel:break` (一気に) と打ちます。

手順3と4は、Minecraft Wikiの「[データパックの読み込み](https://ja.minecraft.wiki/w/チュートリアル:データパックの読み込み)」の説明によります。Minecraft Wikiは、公式のサイトではありません。

## 少しずつ置く (`voxel:build_slow`、試験中)

(図: 下の段から1段ずつブロックが並び、その上を水色の建てる係がきらきら飛び回る3コマ)

`/function voxel:build` の代わりに `/function voxel:build_slow` と打つと、小さな生き物 (アレイ) が建てる係として飛び回りながら、下の段から1段ずつブロックを置いていきます。大きな風景でも、2分ほどで置き終わります。

- 途中で止めたいときは、`/function voxel:build_stop` と打ちます。そこまでに置いたブロックは、そのまま残ります。
- 建てている途中でワールドを閉じて開き直しても、続きから進みます。
- 終わると、建てる係は消えます。

(この置き方は、ゲームの画面で大きな風景 (山と湖・夏、横128マス・山の高さ40マス) を下の段から最後まで置けることを確かめました。終わったときに建てる係がきらきらして消える動きと、途中で止める `/function voxel:build_stop` は、ゲームの画面ではまだ見ていません。)

## 少しずつ壊す (`voxel:break_slow`、試験中)

置いた立体を消したいときは、`/function voxel:break_slow` と打ちます。小さな生き物 (ヴェックス、難易度ピースフルのときはアレイ) が壊す係として飛び回りながら、爆発の粒と音を出して、上の段から1段ずつブロックを消していきます。

- 最後に `/function voxel:build` または `/function voxel:build_slow` で置いた場所を覚えているので、離れた場所から打ってもその立体を壊します。目印がないときは「消す立体の目印が見つかりません」と出て、何もしません。
- 上の段から順に、水はまわりの枠より先に消すので、途中で砂が落ちたり水があふれたりしません。
- 途中で止めたいときは、`/function voxel:break_stop` と打ちます。残ったブロックはそのまま残ります。
- 壊している途中で `/function voxel:build` を打つと、壊す係は止まり、立体が置き直されます。
- 終わると、壊す係は消えます。

(この壊し方は、5種類のファイルで最後までたどると残るブロックが0になることを確かめ、ゲームの画面でも大きな風景を最後まで壊せることと `/function voxel:break_stop` で止められることを確かめました。)

## 一気に消す (`voxel:break`、試験中)

置いた立体を、待たずに一度で消したいときは、`/function voxel:break` と打ちます。壊す係は出てきません。

- `/function voxel:break_slow` と同じく、最後に置いた場所を覚えているので、離れた場所から打ってもその立体を消します。
- 建てる係や壊す係が動いていたら、先に止めてから消します。「いま壊しているところです」と出て先に進めなくなったときにも使えます。
- 消したあとに、もう一度打つと「消す立体の目印が見つかりません」と出ます。目印がなくなった立体は、下の `voxel:break_here` で消せます。
- 立体の下の地面には手をつけません。

(この消し方は、画面のないサーバー用のマインクラフト26.3で、秋の風景を置いて消し、置いた場所のブロックがすべて空気になること、落ちる砂や落とし物が出ないことを確かめました (2026-11-15)。同じ日に、ゲームの画面でも消えることを確かめました。)

## 目印がなくなった立体を消す (`voxel:break_here`、試験中)

`voxel:break` と `voxel:break_slow` は、置いたときの目印を基準に消します。目印がなくなると、「消す立体の目印が見つかりません」と出て、何もしません。そのときは、`voxel:break_here` を使います。

- いちばんかんたんなのは、置いたときにチャットに出た「できあがりました (置いた場所: 座標) [消す]」の [消す] を押すことです。その場所で消すコマンドがチャット欄に入るので、Enterを押します。どこに立っていても消せます。
- 座標をメモしておけば、あとからでも `/execute positioned X Y Z run function voxel:break_here` (X Y Zはメモした座標) と打って消せます。
- 座標がわからないときは、立体を置いたとき (`voxel:build` を打ったとき) と同じマスに立って `/function voxel:break_here` と打ちます。
- 座標や立つ場所が1マスでもずれると、立体の一部が残り、まわりの地面や建物も削ってしまいます。
- いま `datapacks` に入っているファイルの形で消します。別のファイルで置いた立体は、正しく消せません。
- ふだんは `voxel:break` を使い、目印がなくなったときだけ使ってください。

(この消し方は、画面のないサーバー用のマインクラフト26.3で、目印を消した風景を、置いたのと同じマスから消せることと、「できあがりました」の文に出る座標で消せることを確かめました。ゲームの画面でも、[消す] から消せることを確かめました (2026-11-15)。)

## どこに置かれるか

(図: 上から見た図。立っている場所の2マス東に立体の角があり、東と南に向かって置かれる)

- 立っている場所の2マス東が、立体の角になります。そこから東・南・上に向かって置かれます。立っている場所との間は、1マスあきます。
- 高さは、足もとの高さから上です。
- 大きさは、ボクセル工房の画面の左下に「48×17×48」のように出ています。順に、東西・高さ・南北のマスの数です。
- 風景は、まわりに1マスずつ広くなります。水をせき止めるガラスを置くためです。
- 文字は、南側に立って北を向くと読める向きに置かれます。

## 置く前に知っておくこと

- 立体が置かれる場所にもとからあったブロックは、置きかえられます。建物のそばでは実行しないでください。
- 置いた立体は `/function voxel:break_slow` や `/function voxel:break` で消せますが、そこにもとからあった地面や建物が元に戻るわけではありません。はじめは、新しいワールドか、何もない場所で試すのがおすすめです。
- 広くて平らな場所が向いています。ワールドの種類を「スーパーフラット」にすると、見やすくなります。

## 何のブロックになるか

(図: 風景を横から切った断面図。底が石、その上が土と草、木が立ち、端の水の外側をガラスと石の底がせき止めている)

文字と画像の立体は、色のそろった72種類のブロック (コンクリート・羊毛・テラコッタと、石・氷・粘土・砂岩・ろう引きの銅など) から、いちばん近い色のものになります。画面とまったく同じ色にはなりません。保存する前に、本体の「マインクラフトのブロックの色で見る」をオンにすると、置かれるブロックの色で立体を確かめられます。

風景は、次のブロックになります。

| 画面の見た目 | 春・夏・秋 | 冬 |
| --- | --- | --- |
| 草 | 草ブロック | 雪ブロック |
| 土・石・砂・雪 | 土・石・砂・雪ブロック | 同じ |
| 水 | 水 | 氷 |
| 木の幹 | オークの原木 (「マインクラフトの木」では、木の種類ごとにオーク・シラカバ・トウヒ・ポプラ・サクラの原木) | 同じ |
| とがった木の葉 | トウヒの葉 | 同じ |
| 丸い木の葉 | オークの葉・シラカバの葉 (春は、サクラの葉もまじる。秋は、ポプラの葉。下の注を見てください) | オークの葉・シラカバの葉 |

- 水がふちにある所には、外側にガラス (その下端は石) を置きます。1段目の砂も石にしてあります。空中で置いたときにも砂が落ちず、水が外に流れ出さないようにするためです。
- 木の幹の下などの、上がふさがれた草は、土にしてあります。マインクラフトでは、そうした草は時間がたつと土に変わるためです。
- 葉は、時間がたっても消えない設定で置かれます。
- 本体の「木の形」で「マインクラフトの木」を選ぶと、木はマインクラフト26.3の木と同じ形と大きさになります。丸い木はオークとシラカバ (春はサクラもまじる)、とがった木はトウヒとマツ、秋の丸い木はポプラです。「小さな緑の木」は、これらの半分くらいの大きさです。
- 秋の丸い木の葉は、26.3で加わったポプラの葉 (赤・オレンジ・黄色) です。この葉は、どこに置いても色が変わりません。

## 山の上から水を流す (試験中)

風景を保存する前に、本体の「山の上から水を流す」をオンにすると、高い山のいくつか (最大3か所) のてっぺんに水が置かれます。`/function voxel:build` で置くと、水が山を下って流れ、谷を通って湖に入ったり、平らな所に広がったりします。

- 水を置くのは、流れた水が風景の外にこぼれない山だけです。風景の端の近くの山からは、水が崖を落ちてワールドの地面まで流れ出すことがあるため、そうした山には置きません。
- 冬の風景には置きません (湖が氷になっているため)。
- 本体の画面の立体には、この水は出ません。保存したときに出るお知らせに、水を置いた数が出ます。
- 水が流れた所の下の草は、時間がたつと土に変わります。マインクラフトのしくみです。
- `/function voxel:break` などで消すと、流れた水も消えます。

(この設定は、画面のないサーバー用のマインクラフト26.3で、4つの風景 (山と湖・島・なだらかな丘・いちばん高い山の秋の風景) を置き、水が風景の外に出ないこと、まわりの地面が変わらないこと、`voxel:build_slow` で置いても同じことを確かめました (2026-11-20)。ゲームの画面では、まだ見ていません。)

## うまくいかないとき

(図: datapacksフォルダの中に新しいzipを1つだけ入れ、古いzipは外に出す図)

- **「関数が見つからない」という意味の赤い文字が出る**: ファイルが `datapacks` フォルダに入っているか、`/reload` を打ったかを確かめます。ファイルを開いて中身だけを入れた場合は、開く前のファイルを入れ直します。
- **コマンドが使えない**: ワールドの「チートの許可」がオフになっています。
- **立体の一部が置かれない**: 遠くの土地がまだ読み込まれていないと、そこには置かれません。大きな立体で起きやすくなります。マスの数を減らして、作り直してみてください。
- **「いま壊しているところです」(または「いま建てているところです」) と出て、何も始まらない**: 前の係の記録が残っています。`/function voxel:break_stop` (または `/function voxel:build_stop`) と打つか、`/function voxel:break` で立体ごと消してから、やり直してください。
- **「消す立体の目印が見つかりません」と出る**: 立体がまだ残っているなら、置いたときの「できあがりました」の文の [消す] を押すか、置いたときと同じマスに立って `/function voxel:break_here` と打ってください。
- **新しいファイルに入れ替えたのに、前の立体が置かれる**: `datapacks` フォルダに前のzipファイルが残っていると、ファイルの名前を変えていても前のほうが読み込まれることがあります。前のzipファイルは `datapacks` フォルダの外に出すか消してから、`/reload` と打ってください。

## 確かめたこと・まだのこと

- マインクラフト26.3で、文字・画像・風景 (3つの地形、3つの季節、いちばん大きい設定) を置きました。どれも、すべてのブロックが正しく置かれ、ゲームの中の2分後もそのまま残りました (2026-11-14)。この確認は、画面のないサーバー用のマインクラフトで行いました。
- ゲームの画面でも、文字と風景 (山と湖・夏) を置いて見ました (2026-11-14)。風景は、水がガラスの中におさまり、木の葉も残りました。文字は、正しく読める向きに置かれました。
- 文字の色分けに灰色がまじる問題が見つかり、色の選び方を直しました。直したあとの見た目は、ゲームの画面ではまだ見ていません。
- 1.21から26.2までの版では、まだ試していません。
- `/function voxel:build_slow` (建てる係つきで少しずつ置く) は、文字・画像・風景のファイルで、少しずつ置く段階をすべてたどった結果が `/function voxel:build` と同じブロックになることを確かめました。ゲームの画面でも、いちばん大きい設定の風景 (山と湖・夏、横128マス・高さ40マス) を下の段から最後まで置けることを確かめました (2026-11-14)。終わったときに建てる係がきらきらして消えるところと、途中で止める `/function voxel:build_stop` は、ゲームの画面ではまだ確かめていません。
- `/function voxel:break_slow` (壊す係つきで少しずつ壊す) は、文字・画像・風景のファイルで、少しずつ壊す段階をすべてたどると置いたブロックがすべて消え、途中で水や砂が落ちない順序になっていることを確かめました。ゲームの画面でも、いちばん大きい設定の風景を上の段から爆発させながら最後まで消せることと、途中で `/function voxel:break_stop` で止められることを確かめました (2026-11-14)。難易度ピースフル以外でのヴェックスの見た目は、ゲームの画面ではまだ確かめていません。

## ことばの説明

- **Java版・統合版**: マインクラフトには2つの種類があります。Java版はパソコン用です。統合版は、スマホ・ゲーム機・Windows用です。
- **データパック**: マインクラフトのワールドに、あとから足せるファイルのこと。
- **コマンド**: チャットの欄に打ちこむ命令のこと。`/` から始まります。
- **ワールド**: マインクラフトで遊ぶ世界1つ分のこと。
